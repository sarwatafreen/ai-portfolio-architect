# Sarwat Afreen Portfolio

## Goal
Build a polished, responsive personal portfolio for Sarwat Afreen that presents her honestly as a junior frontend and AI web developer, with the AI-Powered Content Studio shown as the main case study.

## What will be built
- A dark charcoal and lime visual system with strong editorial typography, subtle grid texture, selective glass effects, and restrained motion.
- A sticky, mobile-friendly navigation with links to the major portfolio sections.
- Hero, about, skill groups, featured project, AI Studio case study, service capabilities, learning journey, contact call-to-action, and footer.
- A detailed AI Studio showcase covering its audience, services, digital products, technology, and planned features without presenting unfinished work as launched.
- Accessible controls, keyboard focus states, responsive layouts, and reduced-motion support.
- Unique homepage metadata for search and social sharing.

## Content safeguards
- Present Sarwat as a student/fresher and learner-builder.
- Do not invent employers, testimonials, client counts, contact details, social profiles, GitHub links, or completed professional outcomes.
- Treat authentication, cart, wishlist, orders, and admin as planned AI Studio capabilities unless evidence shows they are live.

## Technical approach
- Use the project’s existing React/TanStack Start structure, Tailwind CSS v4, shadcn button primitives, and Lucide icons.
- Keep visual values in semantic design tokens and use CSS animations rather than adding a decoration-only dependency.
- Keep the first delivery focused on the portfolio. The full AI Studio storefront and backend remain a separate implementation milestone requiring Lovable Cloud.

## Verification
- Check the rendered page at desktop and mobile widths.
- Test navigation, visible focus, content overflow, and console errors.
