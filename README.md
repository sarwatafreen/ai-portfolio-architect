## 2. Recommended UI Component Libraries




Leverage pre-built, accessible Tailwind CSS and React component libraries to accelerate development:




1. **shadcn/ui** — Unstyled, accessible component primitives (Dialogs, Tabs, Forms).

2. **Aceternity UI** — Hyper-modern Tailwind + Framer Motion components (Hero glow effects, Bento grids, 3D cards).

3. **Magic UI** — Specialized landing page components (Marquees, Animated Beams, Dock navigation).

4. **21st.dev** — Community-curated React and Tailwind UI snippets.

5. **SmoothUI** — Micro-interactions and polished UI elements.

6. **Skiper UI** — Advanced interactive layout blocks.

## 4. Master Prompt Guide for AI Builders




Use the following prompts in **Cursor**, **Bolt.new**, **Lovable.dev**, or **Gemini** to generate your full portfolio application.




### Prompt 1: Full-Page Portfolio Structure Prompt




```text

Act as a Senior Principal Frontend Engineer and UX Architect. Build a modern, high-converting developer portfolio using Next.js 14 (App Router), Tailwind CSS, Framer Motion, and shadcn/ui.




Key Requirements:

1. Theme & Aesthetic: Dark mode first (slate-950 background), glassmorphism cards, subtle purple/indigo gradient accents, sleek typography (Inter or Geist font).

2. Hero Section:

   - Dynamic headline with gradient text animation.

   - Concise bio, live status indicator ("Available for work"), primary CTA ("View Work"), and secondary CTA ("Get in Touch").

   - Interactive tech stack pill badges with subtle hover glow.

3. Bento Grid Section (Projects & Experience):

   - Asymmetric 3-column bento layout.

   - Project cards featuring tags, live demo links, GitHub links, and sleek image preview placeholders.

4. Skills & Interactive Arsenal Section:

   - Categorized by Frontend, Backend, Tools, and AI Stack.

   - Smooth hover micro-interactions.

5. Experience & Timeline Section:

   - Clean vertical line timeline with company logo, role, bullet points of key achievements, and dates.

6. Contact Section:

   - Clean contact form with client-side validation using Zod.

   - Social links (GitHub, LinkedIn, Twitter/X) with custom SVG icons.

7. Technical Quality:

   - 100% responsive across mobile, tablet, and desktop.

   - Accessibility (WCAG compliant colors and ARIA labels).

   - Smooth scroll navigation with sticky blurred navbar.

```




### Prompt 2: Component Refinement & Animation Prompt




```text

Refine the existing Hero and Projects section using Framer Motion and Tailwind CSS:

- Add a subtle background grid pattern with an animated spotlight blur (`bg-grid-white/[0.02]`).

- Implement staggered entry animations for text elements on page load (`initial={{ opacity: 0, y: 20 }}`).

- Turn project cards into interactive tilt-cards with a smooth border gradient transition on hover.

```

### Authentication




The application uses Supabase Authentication.




Expected flow:




```text

Signup

  ↓

Supabase Auth User

  ↓

Profile data

  ↓

Login

  ↓

Session

  ↓

Protected user features

```




Important distinction:




- Supabase **Authentication → Users** contains authentication accounts.

- `public.profiles` is an application database table for profile information.

- Creating an Auth user does not automatically mean the `profiles` table will contain a row unless the application or a database trigger creates it.
